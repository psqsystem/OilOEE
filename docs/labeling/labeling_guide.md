# Labeling Guide

For each work-order report, the labeler assigns:

1. Failure mode (from controlled taxonomy).
2. OEE component: Availability, Performance, or Quality.
3. Severity: minor, moderate, major.
4. Confidence: low, medium, high.

Rules:

- One report may map to more than one OEE component; record all.
- If the report does not describe an OEE-impacting event, mark as non-OEE.
- Ambiguous reports must be escalated to the supervisor, not guessed.
- Supervisor acceptance or correction is mandatory before training use.
