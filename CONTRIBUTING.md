# Contributing

Accepted contributions:

- Schema proposals for work-order reports.
- Anonymized sample data (never real operator data).
- Labeling guidelines and taxonomy updates.
- Model evaluation results and calibration notes.

Before opening a pull request:

1. Ensure no sensitive or identifying data is included.
2. Run ruff and pytest locally.
3. Reference the governance policy in docs/governance/data_policy.md.
